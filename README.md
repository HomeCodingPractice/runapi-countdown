# RunAPI · 13-Day Sprint Countdown

A responsive, single-file neon terminal countdown page tracking Sprint 1 of the RunAPI project (due 21 November 2026).

## Features
- Live JavaScript countdown to Sprint 1 and the final challenge deadline.
- Mobile-first responsive layout with safe-area support.
- Clean design styled around a custom neon terminal color scheme (`#0B0F1A`, mint `#00E5A8`, and violet `#7C5CFF`).
- Zero external JS library dependencies.
